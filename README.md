# PvZ
Project on the course "Team development of a multifunctional software and hardware complex"

## 3D enclosure

The `3d` branch contains build123d models for the field sensor enclosure.

Main CAD file:

- `sensor_node_enclosure.py` - parametric model for the sensor node base and lid.

Generated print files:

- `sensor_node_field_base.stl` - base with side openings for HW-390, DS18B20, LoRa and GPS antenna bay.
- `sensor_node_field_lid.stl` - lid with screw clearances and inner retaining lip.
